## 4. Correlation Engine Audit: Rules & Evidentiary Nature

The H-MACFR synthesizer implements 4 cross-domain correlation rules with explicit mathematical separation between **DETERMINISTIC FACTS** and **CORROBORATED HYPOTHESES**:

### Rule 1: Process Injection Chain
- **Input Artifacts**: `memory/threat_hunting.json` (malfind), `memory/processes.json` (pslist).
- **Matching Rule**: Exact join on `malfind.PID == pslist.PID` and lookup of `pslist.PPID -> Parent ImageFileName`.
- **Evidentiary Nature**: `DETERMINISTIC_GROUNDED` (Confidence: **0.98**).
- **Justification**: Exact process table tree binding corroborated by kernel memory RWX page allocation.
- **Result on `Bharath_TES1`**: Identified `smss.exe` (PPID: 488) -> `csrss.exe` (PID: 584) code injection.

### Rule 2: Persistence-to-Execution Link
- **Input Artifacts**: `disk/analyzed/run_keys.json`, `disk/analyzed/prefetch_analysis.json`.
- **Matching Rule**: Case-insensitive substring match of executable name from `run_key.command` inside `prefetch.executable_name` where `prefetch.run_count >= 1`.
- **Evidentiary Nature**: `DETERMINISTIC_GROUNDED` (Confidence: **0.96**).
- **Justification**: The exact binary command registered in the registry hive has proven Windows Prefetch run counts.
- **Result on `DISK_1`**: Correlated `VMwareTray.exe` (10 runs) and `VMwareUser.exe` (11 runs).

### Rule 3: Network Socket to Process Lineage
- **Input Artifacts**: `memory/network.json` (netscan), `memory/processes.json` (pslist).
- **Matching Rule**: Exact join on `netscan.PID == pslist.PID` for non-loopback foreign IP addresses.
- **Evidentiary Nature**: `DETERMINISTIC_GROUNDED` (Confidence: **0.95**).
- **Justification**: Direct kernel socket table binding to active volatile process PID.

### Rule 4: Removable Storage Vector (USB Mount)
- **Input Artifacts**: `disk/analyzed/usb_devices.json`, `disk/analyzed/prefetch_analysis.json`.
- **Matching Rule**: Association between USBSTOR hardware enumeration and subsequent telemetry activity.
- **Evidentiary Nature**: `CORROBORATED_HYPOTHESIS` (Confidence: **0.65**).
- **Justification**: *Circumstantial temporal proximity only; physical drive volume path not linked to executable path.* Downgraded from synthetic confidence to prevent research over-claiming.
